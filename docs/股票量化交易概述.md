## 1. 量化交易到底是什么

| 维度 | 主观交易 | 量化交易 |
|---|---|---|
| 决策依据 | 经验、盘感、消息 | 数据、统计规律、模型 |
| 覆盖范围 | 盯得住的几十只 | 全市场几千只，同时监控 |
| 可复制性 | 依赖人，离职即失效 | 代码可复用、可回测 |
| 风险控制 | 事后止损，容易冲动 | 事前规则：仓位、止损、暴露约束 |
| 验证方式 | "感觉自己最近挺准" | 样本内外回测、实盘跟踪、归因分析 |
| 规模 | 资金越大越难 | 可扩容量（但有容量上限） |

量化不等于"高频"，也不等于"稳赚"。它的核心是**把投资决策变成可验证、可执行的流程**。一家量化机构真正值钱的东西是三样：

1. **数据与因子**（别人没有的信息或处理方式）
2. **模型与工程**（把信号稳定地变成收益）
3. **执行与风控**（少亏交易成本，不爆仓）

## 2. 收益从哪里来：量化的底层逻辑

任何策略的收益都可以拆成：

```
总收益 = 市场 Beta + 风格 Beta + Alpha − 交易成本 − 税费
```

- **Beta**：跟着大盘涨跌赚的钱。买指数基金就有，不需要"量化"。
- **风格 Beta**：小市值、低估值、高动量等风格暴露带来的收益。会涨也会崩（如 2017 年小市值因子大幅回撤）。
- **Alpha**：扣掉 Beta 和风格之后，仍然能稳定存在的超额收益。这是量化真正在找的东西。
- **成本**：佣金、印花税、滑点、冲击成本。**成本经常比 Alpha 更大**，尤其在高换手策略里。

量化的一个基本信念是：**市场不是完全有效的，存在可以被数据识别、并且能覆盖交易成本的统计规律。** 这个规律可能来自：

- **行为偏差**：投资者对坏消息反应过度（短期反转）、对好消息反应不足（动量延续）、追涨杀跌、处置效应。
- **结构性约束**：指数调仓、基金申赎、限售解禁、打新、ETF 套利等带来的可预测资金流。
- **信息处理速度差异**：财报、公告、舆情、订单簿信息被更快地解析。
- **风险溢价**：承担某些风险（流动性差、波动大）获得的补偿。

> 判断一个策略是否"真 Alpha"，标准是：**扣掉所有成本、扣掉风格暴露之后，是否还有稳定的正收益，并且在样本外依然成立。**

## 3. 完整实现链路

一条完整的量化流水线：

```
数据采集 ─► 数据清洗/存储 ─► 因子计算 ─► 信号生成 ─► 组合优化/仓位
                                                     │
                    归因与迭代 ◄─ 绩效评估 ◄─ 模拟/实盘 ◄─ 风控 ◄─ 交易执行
```

### 3.1 数据层

**行情数据**

- 日线/分钟线：开高低收、成交量、成交额、换手率、复权因子
- 分钟/逐笔：订单簿快照、逐笔成交（中高频必需）
- 指数与成分股：沪深300、中证500、中证1000、中证2000、创业板指等，以及**历史成分股名单**（不能只用当前成分，否则有幸存者偏差）

**基本面数据**

- 财务报表（利润表、资产负债表、现金流量表），注意**公告日期**而不是报告期，否则就是未来函数
- 估值：PE、PB、PS、股息率、EV/EBITDA
- 分析师预期、盈利预测修正
- 股东结构、限售解禁、股权质押、融资融券余额

**另类数据**

- 新闻舆情、研报文本、公告文本、互动平台问答
- 供应链、招聘、专利、卫星、电商销量、搜索指数
- 龙虎榜、大宗交易、ETF 申赎

**关键工程问题**

| 问题 | 处理方式 |
|---|---|
| 复权 | 回测用**前复权**或**后复权**序列计算收益；成交价用真实价格；分红送转单独记账 |
| 停牌 | 停牌日不交易，估值沿用最后价格，避免"假成交" |
| 退市 | 必须保留退市股票的历史数据，否则幸存者偏差 |
| 缺失值 | 区分"没有数据"和"数据为 0"，前向填充要有时间上限 |
| 时点对齐 | 所有数据带 `available_time`，只允许使用当时已知的信息 |
| 存储 | 小规模用 Parquet/CSV；大规模用 ClickHouse/DuckDB/时序数据库 |

本仓库的 `data/raw/` 已经存了主要指数的日线（上证、深证、创业板、沪深300、中证500/1000/2000 等），`scripts/build_ashare_workbook.py` 里用 MA20/MA60/MA250 做趋势分类，本质上就是一个**最朴素的规则策略雏形**，可以直接作为后续因子研究的基线。

### 3.2 因子层

**因子 = 任何可以横截面比较、并对未来收益有预测能力的数据特征。**

常见因子族：

| 类别 | 代表因子 | 方向 |
|---|---|---|
| 价值 | BP(1/PB)、EP(1/PE)、股息率、CF/P | 便宜的好 |
| 质量 | ROE、ROIC、毛利率、应计利润、资产负债率 | 质量高的好 |
| 成长 | 营收增速、净利润增速、分析师上调比例 | 增长快的可能有溢价 |
| 动量 | 过去 20/60/120 日收益（剔除最近 1 周） | A 股中长期动量弱、短期反转强 |
| 反转 | 过去 1/5/20 日收益取负 | A 股非常显著 |
| 波动 | 历史波动率、特质波动率、最大回撤 | 低波动异象 |
| 流动性 | 换手率、成交额、Amihud 非流动性 | 低换手/低流动性有溢价（但难交易） |
| 规模 | 流通市值、总市值 | 小市值溢价（2017 年后波动很大） |
| 情绪/资金 | 融资余额变化、龙虎榜、北向持仓、大单净流入 | 资金推动 |
| 分析师 | 一致预期、预测调整、覆盖机构数 | 预期修正效应 |

**因子预处理标准流程**（顺序很重要）：

1. **去极值**：MAD 法或 3σ 截尾，防止个别异常值主导
2. **缺失值处理**：行业中位数填充或剔除
3. **标准化**：Z-score，使不同因子可加
4. **中性化**：对行业哑变量、市值、Beta 做回归取残差，剥离风格暴露
5. **合成**：等权、IC 加权、IC_IR 加权、最大化 IC、机器学习模型

**因子有效性检验**

- **IC（信息系数）**：因子值与下期收益的截面相关系数（常用 Rank IC / Spearman）
  - 单因子 IC 均值 > 0.03 已算不错；> 0.05 很好
  - **IC_IR = mean(IC) / std(IC)**，> 0.5 说明稳定性尚可
- **分层回测**：按因子分 5 或 10 组，看各组收益是否单调
- **多空组合**：做多最高组、做空最低组，看净值曲线和换手
- **换手率与容量**：因子即使有效，如果每天换一遍，成本会吃掉一切

### 3.3 信号 → 组合

因子分数只是"排序"，还需要变成实际持仓：

1. **打分**：多因子加权或模型预测得到每只股票的预期收益分数
2. **选股池**：剔除 ST、停牌、上市不足 N 天、流动性不足、涨跌停封死的股票
3. **组合构建**：
   - 简单法：取前 N 只等权
   - 分层法：按分数分档，每档等权或市值加权
   - 优化法：均值-方差优化（MVO）、风险平价、Black-Litterman、HRP，加入行业/风格/个股/换手约束
4. **仓位管理**：目标波动率、最大回撤控制、择时信号（可选，谨慎）

**组合优化的一般形式**：

```
max   wᵀμ − λ·wᵀΣw − c·|w − w₀|₁
s.t.  Σw = 1,  |w_i| ≤ u,  行业暴露 ≤ b,  风格暴露 ≤ s
```

其中 `μ` 是预测收益，`Σ` 是协方差矩阵（常用收缩估计或因子模型估计），最后一项是换手惩罚。

### 3.4 风控

- **事前**：行业/风格暴露约束、单票上限、流动性约束、杠杆上限
- **事中**：实时盯市、异常波动告警、下单频率限制、熔断机制
- **事后**：归因分析（收益来自 Alpha 还是 Beta/风格？）、压力测试、回撤复盘

### 3.5 执行

- **订单类型**：限价单优先，减少滑点；A 股无做空便利时只能先买后卖
- **执行算法**：TWAP、VWAP、POV（按成交量比例）、Almgren-Chriss 最优执行（在冲击成本和风险之间平衡）
- **A 股特殊约束**：
  - **T+1**：当天买入当天不能卖
  - **涨跌停**：主板 ±10%，创业板/科创板 ±20%，北交所 ±30%，ST ±5%（以交易所最新规则为准）；封板时买不进/卖不出
  - **印花税**：卖出单边 0.05%（2023-08 起）
  - **佣金**：约万 1–万 3，另有过户费等
  - **融券受限**：转融券暂停、券源紧张，市场中性策略成本显著上升
  - **停牌、复牌、退市整理期**都要单独处理

### 3.6 归因与迭代

- **业绩归因**：Brinson 归因（行业配置 + 个股选择）、因子归因（Barra 风格暴露贡献）
- **信号衰减**：因子在持有期内的 IC 衰减曲线，决定调仓频率
- **实盘 vs 回测差异**：跟踪误差、滑点偏差，逐日对比，定位是模型问题还是执行问题

## 4. 回测：最容易骗人的环节

回测漂亮 ≠ 能赚钱。常见"作弊"方式：

| 陷阱 | 说明 | 防范 |
|---|---|---|
| **未来函数** | 用了当天收盘后才有的数据做当天决策；用了未公告的财报 | 全部数据带时间戳，信号滞后一期执行 |
| **幸存者偏差** | 只用现在还在的股票回测 | 使用历史全样本，包含退市股 |
| **复权错误** | 用前复权价当成交价；分红重复计算 | 收益用复权价，成交用真实价 |
| **成本忽略** | 不计佣金、印花税、滑点、冲击成本 | 按换手率逐笔扣费，高换手策略尤其要加保守滑点 |
| **成交假设** | 假设涨停也能买到、跌停也能卖出、停牌也能交易 | 用次日开盘价/均价成交，涨跌停日剔除 |
| **参数过拟合** | 调了几百组参数，挑最好的一组 | 样本外验证、滚动前推（walk-forward）、参数敏感性分析 |
| **数据窥探** | 反复用同一段数据试想法 | 预留一段从未看过的数据作为最终检验 |
| **容量问题** | 小资金有效，大资金买不到量 | 按成交额占比限制单票权重（如不超过日均成交额 1%） |

**最小可信回测标准**：

- 样本至少覆盖一轮牛熊（A 股建议 2010 年至今）
- 交易成本：双边至少 0.15%–0.3%（含冲击）
- 有样本外或滚动验证结果
- 结果对关键参数不敏感（参数 ±20% 仍为正）
- 分年度看，不能只靠某一年暴赚

## 5. 主流策略族拆解

### 5.1 多因子选股（Multi-Factor）

**逻辑**：把股票在一组因子上打分，买入综合分高的、卖出/不买分低的。核心假设是"有效因子的收益具有持续性"。

**流程**：因子库 → 预处理 → 因子合成 → 打分排序 → 组合优化 → 定期调仓。

**变体**：

- **指数增强**：在中证500/1000 成分内选股，目标是跑赢指数，约束跟踪误差。国内最主流的量化产品形态之一。
- **市场中性**：多头组合 + 股指期货（IC/IM）或融券对冲，赚纯 Alpha。受基差和券源影响大。
- **全市场选股**：不约束基准，追求绝对收益。

**优点**：可解释、可归因、容量大、工程成熟。
**缺点**：因子拥挤后衰减；单一市场风格切换时回撤大（如 2024 年初小市值/微盘股流动性危机）。

### 5.2 统计套利（Stat Arb）

**逻辑**：寻找价格之间存在长期均衡关系的资产，偏离时反向交易，回归时获利。

- **配对交易**：同行业两只股票价差回归（协整检验、Ornstein-Uhlenbeck 过程建模）
- **ETF 套利**：ETF 价格 vs 一篮子成分股净值，折溢价套利
- **期现套利**：股指期货 vs 现货指数，基差收敛
- **跨期/跨品种套利**：不同月份合约、相关商品之间

**关键**：协整关系是否稳定、交易成本、回归时间、极端行情下的"价差不回归"风险。

### 5.3 趋势跟踪 / CTA

**逻辑**：涨的继续涨，跌的继续跌。用均线、突破、动量信号顺势交易。

- 双均线（MA20 上穿 MA60 买入）
- 唐奇安通道突破（海龟交易法）
- 时序动量：过去 N 个月收益为正则持有
- 波动率目标化仓位：仓位 ∝ 目标波动 / 实际波动

**特点**：胜率不高但盈亏比高，靠少数大趋势赚钱；震荡市连续小亏。在商品期货上更主流，股票上多用于择时和指数增强的辅助信号。

### 5.4 均值回归

**逻辑**：价格偏离均值后会回归。适合震荡市、高流动性标的。

- 布林带、RSI 超买超卖
- 短期反转因子（A 股 1–5 日反转非常显著）
- 网格交易：设定价格区间，跌一格买、涨一格卖
- 日内均值回归：分钟级价差回归（中高频）

**风险**：趋势行情中"越跌越买"会持续亏损，必须有止损和仓位控制。

### 5.5 事件驱动

**逻辑**：特定事件会造成可预测的短期定价偏差。

- 财报超预期（PEAD，盈余公告后漂移）
- 指数成分股调整（调入调出效应）
- 定增、并购重组、股权激励、回购
- 限售解禁、大股东减持
- 打新（A 股特有的低风险收益）
- 舆情/公告文本事件（用 NLP 提取情绪和主题）

### 5.6 高频交易 / 做市 / 执行算法

**逻辑**：赚微观结构里的钱——买卖价差、订单流信息、延迟优势。

- **做市**：双边挂单赚价差（Avellaneda-Stoikov 模型：根据库存和风险调整报价）
- **订单流预测**：用订单簿不平衡（OFI）、成交量分布预测短期方向
- **延迟套利**：更快地反应公开信息（对基础设施要求极高）
- **执行算法**：VWAP/TWAP/POV/冰山单，降低大单冲击成本

**门槛**：低延迟基础设施、交易所席位/托管、逐笔数据、严格的合规。个人基本无法参与。

### 5.7 机器学习 / 深度学习

把"因子合成"变成"模型学习"：

| 方法 | 用途 | 现状 |
|---|---|---|
| 线性回归 + 正则（Ridge/Lasso/Elastic Net） | 因子加权、收益预测 | 仍是重要基线，可解释 |
| GBDT（XGBoost/LightGBM/CatBoost） | 截面收益预测、排序 | **结构化因子数据上的主力** |
| 随机森林 | 稳健的非线性基线 | 常用作对比 |
| MLP / LSTM / GRU / Transformer | 时序建模、价量序列预测 | 头部机构使用，需大量数据与防过拟合 |
| 图神经网络（GNN） | 股票间关联（行业、供应链、资金流） | 研究热点，落地有限 |
| 强化学习 | 组合权重、执行、做市 | 执行/做市有落地，选股端少见 |
| 遗传规划 / 符号回归 | 自动挖掘因子公式 | 因子工厂常用，需严控过拟合 |
| LLM / NLP | 研报、公告、舆情、电话会议文本因子 | 近年增长最快的方向之一 |

**ML 在量化里的特殊难点**：

- 信噪比极低（日频 IC 0.03 已很好），模型极易过拟合
- 样本非独立（时间序列、截面相关），交叉验证要用**时间序列 CV / Purged K-Fold**
- 分布漂移（regime change），模型需要定期重训
- 可解释性要求（合规、归因、风控）

### 5.8 组合优化方法

| 方法 | 核心思想 | 备注 |
|---|---|---|
| 均值-方差优化（Markowitz） | 在给定风险下最大化预期收益 | 对预期收益极敏感，需收缩/约束 |
| Black-Litterman | 市场均衡收益 + 主观观点融合 | 适合机构配置 |
| 风险平价（Risk Parity） | 各资产风险贡献相等 | 股债配置常用 |
| 最小方差 / 最大分散化 | 降低组合波动 | 稳健，常作基线 |
| HRP（层次风险平价） | 聚类后分层配置，避免协方差矩阵求逆不稳定 | 近年流行 |
| 因子模型组合 | 用 Barra 类风险模型约束暴露 | 指数增强标配 |

## 6. 现在主流的算法是什么

先给结论：**不存在一个"最强的主流算法"，主流是按资金规模、频率、市场分层的。**

### 按参与者分层

| 层级 | 典型做法 | 核心技术 |
|---|---|---|
| 个人 / 小资金 | 规则策略（均线、动量、网格）、简单多因子、ETF 轮动 | Python + pandas + 券商 API |
| 中小私募 | 多因子 + 机器学习打分（LightGBM 为主）、指数增强、中性 | 因子库 + 回测框架 + 组合优化 |
| 头部量化私募 | 大规模因子库 + 非线性模型 + 组合优化 + 高频执行 | 自研因子平台、深度学习、低延迟交易 |
| 高频/做市机构 | 订单簿建模、做市、延迟套利 | C++/FPGA、逐笔数据、托管机房 |

### 当前（2020s）的技术共识

1. **多因子框架仍是骨架**。无论用什么模型，最终都是"特征 → 预测 → 组合"的流程。因子工程（数据清洗、中性化、正交化）比模型选择更重要。
2. **GBDT 是结构化数据上的实际主力**。LightGBM/XGBoost 在截面收益预测上稳定、训练快、对缺失值鲁棒，是大多数私募的默认选择。线性模型仍是重要的可解释基线。
3. **深度学习是增量而非替代**。LSTM/Transformer 在价量序列、高频数据上有优势，但日频选股上相比 GBDT 的增益有限，且更依赖数据和算力。头部机构用"深度模型 + 集成"提升边际。
4. **强化学习主要落在执行和做市**，而不是选股。选股端 RL 面临奖励稀疏、环境非平稳的问题。
5. **LLM/NLP 是增长最快的新方向**：公告解读、研报摘要、舆情情绪、电话会议纪要，正在成为新的因子来源。
6. **因子挖掘自动化**：遗传规划、符号回归、AutoML 构建"因子工厂"，配合严格的样本外检验。
7. **组合优化越来越重要**：同样的 Alpha，优化后的组合能显著提升夏普、降低回撤。Barra 类风险模型是标配。

### A 股的特殊主流

- **量价因子主导**：A 股散户占比高，短期反转、换手率、波动率、资金流类因子非常有效。
- **小市值/微盘因子**：长期有效但 2024 年初经历剧烈回撤，暴露了流动性和拥挤风险。
- **指数增强 + 中性**：主流产品形态。中性策略受融券和期指基差制约。
- **打新、ETF 套利、可转债**：低风险收益的重要补充。
- **T+1 与涨跌停**：限制了高频和日内策略，A 股量化频率普遍低于美股。

### 一句话回答"现在主流是什么"

> **中低频：多因子 + LightGBM/线性模型打分 + 组合优化，这是行业默认配置；中高频：订单簿特征 + 深度学习/树模型 + 低延迟执行；前沿：LLM 文本因子与自动化因子挖掘。**

## 7. 最小可运行示例

用一个"短期反转因子"跑通：因子计算 → IC 检验 → 分层回测 → 绩效评估。代码只依赖 `numpy` / `pandas`。

```python
import numpy as np
import pandas as pd

# ------------------------------------------------------------
# 输入：long_df，列为 [date, code, close, amount]
# 输出：宽表（index=date, columns=code）
# ------------------------------------------------------------
def to_panel(long_df, value="close"):
    return long_df.pivot(index="date", columns="code", values=value).sort_index()

# ------------------------------------------------------------
# 1. 构造因子：20 日反转（跌得多的得分高）
# ------------------------------------------------------------
def reversal_factor(close, n=20):
    return -(close / close.shift(n) - 1)

# ------------------------------------------------------------
# 2. 前瞻收益（注意：用 shift(-h)，回测时只用于评估，
#    实盘决策只能用 t 日及之前的数据）
# ------------------------------------------------------------
def forward_return(close, h=5):
    return close.shift(-h) / close - 1

# ------------------------------------------------------------
# 3. Rank IC：每个截面上因子排名与未来收益排名的相关
# ------------------------------------------------------------
def rank_ic(factor, fwd, min_stocks=50):
    out = {}
    for d in factor.index:
        a, b = factor.loc[d], fwd.loc[d]
        mask = a.notna() & b.notna()
        if mask.sum() >= min_stocks:
            out[d] = a[mask].rank().corr(b[mask].rank())
    return pd.Series(out).dropna()

# ------------------------------------------------------------
# 4. 分层回测：每期按因子分 5 组，等权持有 h 天
# ------------------------------------------------------------
def quantile_returns(factor, fwd, q=5, min_stocks=50):
    rows = []
    for d in factor.index:
        a, b = factor.loc[d], fwd.loc[d]
        mask = a.notna() & b.notna()
        if mask.sum() < max(min_stocks, q * 10):
            continue
        groups = pd.qcut(a[mask].rank(method="first"), q, labels=False)
        rows.append(b[mask].groupby(groups).mean())
    return pd.DataFrame(rows)

# ------------------------------------------------------------
# 5. 绩效指标
# ------------------------------------------------------------
def stats(returns, periods_per_year=252):
    r = returns.dropna()
    nav = (1 + r).cumprod()
    ann_ret = nav.iloc[-1] ** (periods_per_year / len(r)) - 1
    ann_vol = r.std() * np.sqrt(periods_per_year)
    sharpe = ann_ret / ann_vol if ann_vol > 0 else np.nan
    mdd = (nav / nav.cummax() - 1).min()
    return {
        "年化收益": round(ann_ret, 4),
        "年化波动": round(ann_vol, 4),
        "夏普": round(sharpe, 2),
        "最大回撤": round(mdd, 4),
        "胜率": round((r > 0).mean(), 3),
    }

# ------------------------------------------------------------
# 使用
# ------------------------------------------------------------
# close = to_panel(long_df)
# f     = reversal_factor(close, 20)
# fwd   = forward_return(close, 5)
#
# ic = rank_ic(f, fwd)
# print("IC均值:", ic.mean(), "IC_IR:", ic.mean() / ic.std())
#
# qret = quantile_returns(f, fwd, q=5)
# long_short = qret[4] - qret[0]          # 最高组 - 最低组
# print(stats(long_short))
```

**把这个示例做到"可信"还需要补**：

1. 真实数据、真实复权、剔除停牌和 ST
2. 按换手扣费（每次调仓双边约 0.15%–0.3%）
3. 滚动窗口检验（walk-forward），而不是全样本一次回测
4. 分年度、分市值段看稳定性
5. 多因子合成，而不是单因子

## 8. 评价指标

| 指标 | 公式/含义 | 参考值 |
|---|---|---|
| 年化收益 | 净值年化增长率 | 越高越好，但要看风险 |
| 年化波动 | 日收益标准差 × √252 | 越低越稳 |
| **夏普比率** | (年化收益 − 无风险利率) / 年化波动 | > 1 合格，> 2 优秀 |
| **最大回撤** | 净值从高点到低点的最大跌幅 | 决定你能否拿得住 |
| Calmar | 年化收益 / 最大回撤 | > 1 较好 |
| 胜率 | 盈利期数占比 | 与盈亏比配合看 |
| 盈亏比 | 平均盈利 / 平均亏损 | 趋势策略依赖此项 |
| **IC / IC_IR** | 因子预测能力 / 稳定性 | IC > 0.03，IR > 0.5 |
| 换手率 | 每期换仓比例 | 越高成本越大 |
| 跟踪误差 | 相对基准的波动 | 指数增强要控制 |
| 容量 | 策略能容纳的资金规模 | 常被忽视，却决定上限 |

**最重要的不是收益，而是"收益/回撤"和"收益是否可重复"。**

## 9. 从想法到上线的检查表

**研究阶段**

- [ ] 想法有明确的经济/行为逻辑（为什么这个规律存在？）
- [ ] 数据没有未来函数，包含退市股
- [ ] 因子经过去极值、标准化、中性化
- [ ] IC、分层、多空三套检验都通过
- [ ] 参数敏感性测试通过
- [ ] 滚动样本外验证通过
- [ ] 扣除保守交易成本后仍有正收益
- [ ] 容量测算合理

**工程阶段**

- [ ] 数据管道可复现，每日自动更新
- [ ] 回测与实盘使用同一套信号代码
- [ ] 有实盘前的模拟盘（paper trading）阶段
- [ ] 有异常告警（数据缺失、信号异常、下单失败）
- [ ] 有熔断和手动干预开关

**上线后**

- [ ] 每日对比实盘与回测的偏差
- [ ] 定期归因：收益来自 Alpha 还是风格
- [ ] 监控因子拥挤度和衰减
- [ ] 定期重训模型、更新因子库
- [ ] 回撤超过阈值时降仓或暂停

## 结语

量化的门槛不在"算法有多复杂"，而在三件事：

1. **想清楚收益来源**（为什么这个规律会存在，谁在亏钱）
2. **把回测做诚实**（成本、滑点、样本外、幸存者偏差）
3. **把流程做稳定**（数据、信号、执行、风控可复现）

大多数人的失败不是因为模型不够先进，而是因为回测太乐观、成本没算够、策略拥挤后还在硬扛。**先把一个简单的多因子 + 严格回测跑通，再谈机器学习和深度学习。**
